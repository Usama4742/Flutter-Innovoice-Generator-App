# 🧾 Flutter Invoice Generator

A modern invoice management application built with **Flutter and Dart** that helps users create, manage, edit, and share professional invoices. The application uses SQLite for local data storage and Provider for state management.

## ✨ Features

* 🧾 **Invoice Management** — Create, view, edit, and delete invoices.
* 🗄️ **SQLite Database** — Store invoice information locally.
* 🔄 **Provider State Management** — Manage application state and refresh invoice data.
* 📄 **PDF Generation** — Generate professional PDF invoices.
* 🔳 **QR Code Generation** — Include invoice-related QR codes in generated PDFs.
* 📷 **QR Code Scanning** — Scan an invoice QR code to retrieve the corresponding saved invoice.
* 💰 **Payment Status Tracking** — Manage invoice payment statuses.
* 👤 **Vendor and Customer Details** — Store and update names, contact information, and addresses.
* 📅 **Date and Time Management** — Set and update invoice dates and times.
* 📤 **Invoice Sharing** — Share PDF invoices through supported apps.
* 📊 **Dashboard** — View invoice information and financial summaries.
* 🌙 **Dark and Light Themes** — Switch between themes for a comfortable user experience.
* 🎨 **Modern UI** — Clean interface with reusable components and consistent styling.

## 🛠️ Technologies Used

* **Flutter** — Cross-platform UI development
* **Dart** — Application programming language
* **SQLite** — Local database
* **Provider** — State management
* **PDF** — PDF document generation
* **Printing** — PDF preview and printing
* **Share Plus** — Sharing invoice documents
* **QR Code** — Invoice identification and scanning

## 🚀 Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* Android Studio or Visual Studio Code
* An Android emulator or physical device

### Installation

1. Clone the repository:

   ```bash
   https://github.com/Usama4742/Flutter-Innovoice-Generator-App/
   ```

2. Open the project directory:

   ```bash
   cd https://github.com/Usama4742/Flutter-Innovoice-Generator-App/
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

## 💾 Data Storage

The application uses SQLite to store invoice records locally on the device. Invoice information can be retrieved and updated through the application's database and Provider layers.

## 🔐 Privacy

Invoice data is stored locally by default. Sharing or exporting an invoice may send its contents to the destination selected by the user.
